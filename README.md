# GLB-3D-Viewer GLB 立體檢視器
GLB 立體檢視器目前具備的功能：

檢視與操作

滑鼠拖曳左右/上下可旋轉模型，滾輪縮放
觸控裝置支援拖曳旋轉、雙指縮放，版面在手機寬度會自動換行排列
「自動旋轉」「重設視角」按鈕
「開啟 GLB…」可隨時換成電腦裡其他的 .glb/.gltf 檔案（純瀏覽器端讀取，不會上傳到任何伺服器）
右上角「光源亮度」滑桿，可調整場景明暗（20%~220%）
左下角顯示目前模型的三角面數與檔名
支援淺色/深色主題自動切換
技術重點

用 Three.js 渲染，函式庫與模型資料都直接內嵌在 HTML 裡，不需連網即可運作
修正過畫面置中/裁切的渲染尺寸問題
兩種取用方式

線上版（Artifact 連結）：隨時可在瀏覽器打開，之後若還要調整我可以直接修改
下載版（單一 .html 檔，約 3.5MB）：離線也能雙擊開啟使用，適合分享給別人或長期保存
目前內建的模型是你附加的「無敵鐵金剛.glb」，之後想看別的模型直接按「開啟 GLB…」選檔即可。
